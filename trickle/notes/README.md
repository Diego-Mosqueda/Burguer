# BH Restaurant Landing Page

## Overview
Modern, minimalist one-page landing page for "BH" (Burritos & Hamburguesas) restaurant, focused on high UX/UI and conversion through WhatsApp orders.

## Design Style
- **Minimalist aesthetic** with generous white space
- **Glassmorphism effects** on navbar
- **Color palette:**
  - Primary Orange: #FF6600 (CTAs)
  - Primary Yellow: #FFC107 (Secondary CTAs)
  - Dark Gray: #343A40 (Text)
  - Light Gray: #F8F9FA (Background)
  - Social Blue: #1877F2 (Social icons only)

## Technology Stack
- React 18
- Bootstrap 5.3
- AOS (Animate On Scroll)
- Google Fonts (Poppins)
- Lucide Icons

## Sections
1. **Navbar** - Sticky navigation with glassmorphism
2. **Hero** - Full-screen impactful visual with main CTA
3. **Menu** - Featured menu items with hover effects
4. **About** - Restaurant philosophy and values
5. **Contact** - Location map and contact information
6. **WhatsApp Button** - Floating CTA for orders

## Key Features
- Fully responsive design
- Smooth scroll animations
- Hover effects on cards and buttons
- Floating WhatsApp button with pulse animation
- Google Maps integration
